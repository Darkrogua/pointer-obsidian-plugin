# Инструкция для разработки плагина

### Компиляция
1.  Устанавливаем зависимости
    ```bash
    npm i
    ```
2.  Компилируем typeScript
    ```bash
    npx tsc --project tsconfig.json
    ```
3.  Компилируем с копированием в нужную папку для тестов (предварительно надо скорректировать пути в **package.json**)
    ```bash
    npm run build:copy
    ```
